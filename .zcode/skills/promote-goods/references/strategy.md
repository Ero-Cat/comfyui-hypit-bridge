# promote-goods 流量算法 → 生成配方映射（strategy）

两版算法研究全文见 `algorithm-research.md`（启发式科研模型，非官方）。本文件只保留
**生成侧可执行**的结论：把每个权重因子翻译成视频结构规则，让模型产出的每条片子
在算法口径下先天最大化。

## 1. 算法因子 → 视频结构规则

| 算法因子（权重） | 生成配方 | 落点 |
| --- | --- | --- |
| R2 两秒留存（内容力 30%） | 第 1 拍 0–1.5s = 视觉钩子：商品极致特写 / 痛点场景 / 效果反差；**禁品牌片头、禁慢起** | 窗 1 首句动作 |
| R5 五秒留存（25%） | 第 2 拍把钩子落成悬念/痛点场景 | 窗 1 中段 |
| **商品点击 CTR（商业力 40%）** | **≤3s 商品必须入画且可识别**；全程商品在场；利益点进字幕 | 窗 1 商品在 2s 内出现 |
| 完播/观看深度（25%+20%） | 默认 **16s**（2 窗零浪费格网定点）；台词 0.33s/字；窗尾收口留 ≥1s；结尾回扣开头成环（loop 友好） | 时长决策 |
| 分享率+收藏率（互动权重最高 30%+25%） | 内容给「可收藏价值」：多场景用法/选购维度/做法演示；文案埋「先收藏」钩 | 窗 2 演示密度 |
| 评论率（20%） | 疑问/立场句式（建议放发布文案而非口播，省台词预算） | 发布文案模板 |
| CVR 成交转化（40%） | 信任素材来自采集文案的可验证事实（规格/分量/真实评价）；CTA「点下方小黄车」 | 窗 2 信任拍 |
| 客单质量（20%） | 分量/规格事实呈现（如「一大桶」），不做价格对比 | 窗 2 |
| 风险门控（→0 分） | 合规双闸 `check_compliance.py`（见 §2），FAIL=0 才呈卡 | 全流程 |
| 账号力（放大器 0.8–1.2×） | 生成侧不控；同账号按类目固定模板族保证垂直度 | 模板库 |
| 流量动量（10%） | 发布侧指标，生成侧无关 | — |

## 2. 合规净化规则（2026-09-27 用户《选品与剪辑规范》+补充，工具已内置）

文案双闸（`tools/check_compliance.py`，①采集文案净化建议 mode=copy ②脚本门控 mode=script）：

| 禁项 | 处理 |
| --- | --- |
| 极限词六类（最/一/顶级/首家·国/绝对极限/权威，含 NO.1、驰名商标、特供等全表） | 剔除或降级改写 |
| **产品具体功效** | **润色成体验/场景/人群语言**：说「烧鱼炖肉时倒一点」不说「去腥增香」 |
| **配料表** | 不提不念不特写 |
| **价格** | 全链路去除（数字+元/券/特价/秒杀价…）；佣金实时变动，视频里的价必失效 |
| **时间信息** | 促销时限/日期/双11/保质期类全去除 |
| **产地** | 「产地/产自/原产」+ 每商品 `--extra-origin` 名录（如 绍兴,太湖） |
| 名人 / 暗示食用使用后效果 | 不涉及（含「一用就/越喝越」句式） |

视觉策展：带价格标签/日期/产地标注/配料表特写/营销文字的素材剔除或裁切；
**包装一致性**（同 SKU 来源+目检）；商品视频先去音轨再作参考。
边缘词（便宜/实惠/包邮/新品…）WARN 人工复核。

## 3. 引擎与生成时间预算（2026-09-28 终测定案：社区加速器双双否决，产线=干净内存 turbo 档）

**终极测评（v1–v5，同脚本同参考单变量对照，31s/780 帧）**：

| 轮 | 配置 | 耗时 | s/帧 | 提速 | 质量判定 |
| --- | --- | --- | --- | --- | --- |
| v1 | 20 步质量档 + awq TE | 54m50s | 4.22 | 1.0× 基准 | ✅ 交付 |
| v2 | turbo8+SolAttn + awq TE | 58m29s | 4.49 | — | ✅ 交付（步数不是瓶颈） |
| v3 | 同 v2（主机内存污染轮） | 2h59m | 13.8 | 作废 | 质量过/耗时数据废 |
| v4 | + EasyCache(0.2) + heretic TE + 清内存 | 18m24s | 1.42 | 3.2× | ❌ **用户否决**：盖上了还能倒酒（事件因果崩）、平移往返场景已变（实体持久崩）、物理违例 |
| v5 | + Spectrum + heretic TE + 清内存 | 15m57s | 1.23 | 3.7× | ❌ 窗1 事件因果已修复 ✅，但窗2 场景回归仍崩（排骨碗↔整鱼凭空增删/换位）+ 25→26s 商品桶变琥珀半透明（包装一致性硬伤） |

**结论**：两家社区加速器都过不了带货质量门（实体持久性/包装一致性）。**产线交付档 =
turbo8 LoRA + SolAttn + heretic NVFP4 TE + 加速器全关 + 提交前 `POST /free` 清内存**。
这是唯一缺测格（v2 的 58m29s 是 awq TE+脏内存时代数字；v3 证明内存压力可致 3× 膨胀，
清内存本身贡献了 v4/v5 提速的大头）——**呈卡按 ≤58min 上界报价，产线首条实测后修正**。
**Spectrum 降级为草稿预览档**：15m57s/3.7× 且窗1 事件因果完好，适合出粗版给用户预看
节拍/台词节奏；终版必须无加速器渲染（草稿渲染也照走 §2 确认卡）。

QC 方法论（随 v4 否决升级）：1fps 静帧看不出「盖上还倒酒」类因果违例——事件段
（开盖/倾倒/平移往返）加抽 **fps=2 帧带** 做因果核查，再 1fps 全片网格 + 人眼终审。

**运维注（呈卡/提交前必做）**：① 提交前 `POST /free`（unload_models+free_memory）——
RAM 预检 <12.7GB 会直接拒（2026-09-28 实锤 5.9GB 被拒）；② 大渲染前确认主机空闲 RAM
≥16GB（内存压力会让权重反复换页，渲染时间膨胀数倍，v3 的 2h59m 疑与此相关）；
③ 单卡并发 1，排队另计；runtime 改动后 `hypit runtime down && up`（仓库根）。

## 4. 时长与格网决策

- 16s = 2 窗零浪费唯一定点（192 帧/窗恰在 17k+5 格网）——**带货默认**。
- 更短物理不可行（链式 ≥16）；要更长的信任型类目用 31s 档（3 窗），先按 provider
  格网规则核帧数再呈卡。
- 台词预算 0.33s/字：16s ≤40 字；31s ≤85 字（收口 ≥1s）。
- 画幅：链式属性不生效，**ref-1 必须竖屏锚图 736×1280**；单镜头路径显式
  `aspect-ratio="9:16"`。

## 5. 发布侧备忘（最终交付必附，2026-09-27 用户定规）

- **每次交付成片必附「发布文案建议」**（SKILL.md §8）：首句钩子/正文短句/评论引导
  （具体问题）/话题标签 3–5 个，骨架与类目标签库见 `templates.md`。
- 发布文案**与视频同口径过合规闸**（价格/时间/产地/功效/配料表/极限词同样禁止；
  标签不用价格暗示词与功效词）。
- 挂车后冷启动 2–6h 窗口回收 R2/R5/完播/CTR/CVR 数据 → 若自建归因，评分模型见
  `algorithm-research.md` V3/合成版公式（分桶分位数归一 + 账号力乘数 + 风险门控）。
