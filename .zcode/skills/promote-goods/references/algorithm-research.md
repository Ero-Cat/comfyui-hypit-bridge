## 一、抖音带货短视频「优秀爆款」流量权重算法（最终合成版 · 含账号力）

**适用**：带货类短视频（挂车）的素材评分、筛选、爆款预测与归因研究。
**设计原则**：同类目+同价格带+相近时长分桶分位数归一化；乘法漏斗 × 板块加权 ×
账号力放大 × 风险门控。

### 1. 数据口径
- 分桶：同类目+同价格带+时长±20% 桶内归一化；分位数 q(x)∈[0,1]
- 样本守卫：播放 ≥300 才评分；只用发布后 2–6h 冷启动窗口（防前视偏差）
- 指标可得性：留存/互动（创作者中心✅）、2/5s 留存（⚠️退化）、电商漏斗（罗盘✅）、
  负反馈明细（❌删除）

### 2. 板块划分
| 板块 | 代表指标 | 逻辑 |
| --- | --- | --- |
| 内容力（留存-完播） | R2、R5、完播、平均播放占比 | 决定有没有下一波流量 |
| 传播力（互动） | 分享、收藏、评论、点赞、关注 | 决定内容放大（分享/收藏权重最高） |
| 商业力（转化） | CTR、CVR、客单价 | 决定商业流量（GPM 三因子分解，不重复计权） |

账号级五因子（放大器）：领域垂直度、粉丝画像匹配度、粉丝量级（log）、铁粉占比、
历史领域权重。

### 3. 核心公式
```
爆款预测分 = (25%×内容留存 + 20%×互动传播 + 20%×商品点击 + 20%×成交转化
             + 15%×客单质量) × 账号力乘数 − 风险扣分（门控）
账号力乘数 = 0.80 + 0.40×账号力分 ∈ [0.80, 1.20]

爆款指数（乘法/科研） = 内容力 × 传播力 × 商业力 × 账号力分   （短板效应）
GMV = 曝光 × CTR × CVR × 客单价；GPM = 1000×CTR×CVR×客单价
风险门控：违规/虚假宣传/异常营销/高退货/差评/体验分低 → 指数×0
```
子公式权重：内容留存 40/25/20/15（无 R2 时退化 60/40）；互动传播 30分享/25收藏/20评论/
15点赞/10关注；商业效率 40CTR/40CVR/20客单。

### 4. 回归标定（进阶）
log(爆款指数) = β0 + Σβi·log(q_i)；晋级标签逻辑回归 / log(净GMV) 线性回归；
AUC + 分组验证（预测高分组的实际 GMV 提升），不用全样本拟合优度。

### 5. 注意事项（要点）
权重需按类目重标定（坊间 2026 口径：收藏/复访/铁粉权重升、完播退居第五）；
粉丝量 log 边际递减、铁粉占比比粉丝数更能预测互动质量；账号力是放大器不能掩盖内容差；
垂直度/历史权重用 30/90 天滚动窗口。

## 二、抖音优秀爆款商品短视频权重算法 V3

### 1. 最终核心公式
```
Score = 0.75V + 0.15A + 0.10M − Penalty
V(单条视频质量) = 0.40C(内容消费) + 0.25I(互动传播) + 0.35E(电商成交)
核心原则：视频表现 > 账号历史 > 粉丝绝对数量
```

### 2. V 展开
- C = 0.30R2 + 0.25R5 + 0.25完播 + 0.20观看占比（W=平均观看时长/总时长）
- I = 0.20点赞 + 0.24评论 + 0.28分享 + 0.16收藏 + 0.12关注（分母统一播放量）
- E = 0.286CTR + 0.286CVR + 0.286GPM + 0.142Q(商品/服务质量)

### 3. A 账号综合权重 = 0.30D垂直 + 0.20U人群匹配 + 0.15H历史内容 + 0.15B历史商业
\+ 0.10Fa有效粉丝 + 0.10T可信度
- D = 0.4D_count(同领域视频占比) + 0.6D_traffic(同领域观看时长占比)
- U = 0.40内容×商品 + 0.35人群×商品 + 0.25历史相似品转化
- Fa = 规模(log,基准100万封顶) × 活跃 × 精准；有效粉 = 粉丝×活跃率×匹配度
  （10万精准粉 > 100万泛粉）
- H = 0.35中位数V + 0.25P75 + 0.20稳定性(1−CV) + 0.20爆款命中率（用 P50/P75/P90，防单爆款拉偏）
- B = 0.30CTR_h + 0.30CVR_h + 0.30GPM_h + 0.10复购
- T = Trust − Risk（资质/履约/低违规 − 违规/高退款/异常涨粉）

### 4. M 流量动量 = 0.40Velocity + 0.25Acceleration + 0.20Competition + 0.15NonFan
- Velocity = 实际首小时播放 / 预期首小时（预期=f(粉丝,领域,历史,发布时间,类型)）
- 非粉突破率 = 非粉播放/总播放（真爆款必破圈）

### 5. Penalty 风险处罚
```
Penalty = 0.04负反馈 + 0.03退款 + 0.03差评售后 + Risk
虚假宣传/严重违规 → 强制大幅降权或判零（门控不是线性扣分）
```

### 6. GMV 严格漏斗
```
GMV = 曝光 × 播放率 × 商品点击率 × 点击成交率 × 客单价
曝光→播放→R2→R5→观看深度→互动→商品点击→成交→GMV→退款/售后
```

### 7. 归一化与评级
- 用 PercentileRank（桶内：类目/价格带/时长/账号规模/流量来源），不用 benchmark 封顶
- 评级：<0.45 D / 0.45–0.60 C / 0.60–0.72 B / 0.72–0.82 A / 0.82–0.90 S / >0.90 S+
- 升级方向：Logistic/XGBoost/LightGBM 预测破万播放/Top10%/目标GPM/爆款区间

### 8. 一句话浓缩
**爆款 = 留得住 × 看得深 × 愿传播 × 领域匹配 × 人群精准 × 想点击 × 能成交 × 能破圈 × 低风险**
一级权重：75% 单条实时表现 + 15% 账号先验 + 10% 冷启动赛马 − 风险处罚。

## 三、《选品与剪辑规范》要点（2026-09-27 用户提供，截图+补充）

- 混剪规范：所选品视频夸张能量越大越好，但**不可涉名人**；禁止视频价格与商品页不一致
  （→ 全链路无价格）；禁止暗示性「吃完后就 XX」话术。
- 禁用极限词六类（规范截图全表）：**最** / **一**（第一、唯一、首个…）/ **顶级**（顶级、
  极品、王牌…）/ **首家·国**（国家级、世界级、特供、驰名商标…）/ **绝对极限**（100%、永久、
  万能、根治…）/ **权威**（专家认证、专利…）。工具化：`tools/check_compliance.py`。
- 剪辑优化约束（补充定规）：产品具体功效在标题/文案润色成其他内容；配料表不提；
  主食材段不能纯音乐（须口播覆盖，本管线 H3 全程口播天然满足）；不同素材商品包装一致；
  辅素材产品一致；去除时间信息、价格标签、产地信息。
- 巨量千川审核规范：https://qianchuan.jinritemai.com/school/helpcenter/article/625
