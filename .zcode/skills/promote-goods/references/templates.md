# promote-goods 类目模板库（templates）

结构件而非固定文案：每商品仍定制脚本。通用骨架 = **钩子拍 → 演示/信任拍 → CTA 拍**，
全部落 16s/2 窗（窗 1=钩子+商品入画，窗 2=演示+信任+CTA）；高客单/信任型类目用 31s/3 窗
（窗 3=信任深化+CTA）。每窗必有口播，无纯音乐窗。

## 通用台词骨架（高频高节奏版，2026-09-27 用户定规）

带货口播=高频轰炸：**短句 5–11 字、每 2.5–3.5s 一个信息点、语音占片长 ≥80%**。
总量：31s 片 80–95 字 / 16s 片 45–55 字（上限 2.7字/s 不破）。

```
窗1（钩子轰炸，0–1/3）：痛点句(≤9) → 商品带入句(≤11) → 认同句(≤8)
窗2（用法矩阵快切，中段）：动作短句×3 排比(各≤7，每句对准一个镜头动作) → 收藏钩(≤6)
窗3（信任+CTA，尾段）：分量/规格句(≤11) → 信任句(≤8，真实评价或规格事实) → 命令式CTA(≤8)
```

句式库（高频节奏工具箱）：
- 数字冲击：「五斤一大桶」「三个用法」「一勺就够」（数字=事实，不是价格）
- 反问钩：「还在买小瓶装？」（窗1 开场可选）
- 排比快切：「腌排骨倒一点 / 烧鱼淋一圈 / 炖煮焖炒样样行」——每半句对准一个画面动作
- 命令式 CTA：「先收藏，别刷走」「要的，点下方小黄车」
- 节奏锚：句间隔 ≤1s；soundscape 不留长空白段（稀疏=加词风险+掉留存）

**禁**：一句台词配 3 秒空镜的"文艺慢片"节奏；长复句（>14 字拆两句）；连续两句无信息增量。

## 六类目模板

### 1. 美妆个护
- 钩子模式：**前后反差**（素颜局部→上妆）/ 质地特写（膏体拉丝、精华滴落）
- 三拍：质地特写→上脸过程→妆效展示（窗2 信任拍=成分体验场景，**不提功效词**）
- 声景：瓶盖开合、膏体搅拌、轻拍面部、化妆刷摩擦；台词（示例骨架）：「上脸这一下，就知道值不值。」
- 禁词重点：美白/抗皱/祛痘等功效全禁；改写为「化完这个妆朋友问了我三次」类体验句
- 参考：产品瓶身多角度+质地特写+使用场景图

### 2. 食品饮料（试点花雕料酒所属类目）
- 钩子模式：**烹饪动作瞬间**（倒酒/浇汁/拉丝）+ 热气/食欲特写
- 三拍：烹饪使用场景→成品餐桌展示（分量感）→商品 hero 定格
- 声景：烹饪滋滋声、液体倾倒、餐具轻碰、蒸汽声；台词骨架「炖肉烧鱼，就差这一勺。」
- 禁词重点：产地（--extra-origin 按商品补）、去腥增香解腻类功效、配料表、暗示食用后效果
- 主食材镜头（生肉/鱼/谷物特写）**必须有口播覆盖**（用户混剪规则对齐）

### 3. 数码3C配件
- 钩子模式：**痛点场景**（线缠绕/充电慢/摔落）→ 商品介入瞬间
- 三拍：痛点演示→功能特写（接口/磁吸/指示灯）→ 上机收纳完成态
- 声景：卡扣声、磁吸吸附、键盘/电流细节声；台词骨架「桌面乱成一团？这个一贴就完事。」——
  注意「一贴就完事」涉暗示效果？否：描述动作完成，非身体功效；但**效率承诺类慎用**，审核口径从严
- 禁词重点：速度/容量等参数夸大（用规格事实）、「军工级/国家级」

### 4. 家居日用
- 钩子模式：**改造前后**（台面杂乱→整齐）/ 使用瞬间（一拉一扣）
- 三拍：痛点空间→商品安装/使用动作→完成态全屋感
- 声景：安装咔哒、织物摩擦、水流/开合声；台词骨架「出租屋也有春天，全靠它。」
- 禁词重点：材质绝对化（「最耐用」）、除菌/防螨功效词

### 5. 服饰箱包
- 钩子模式：**上身瞬间**（一镜到底换装动作）/ 面料垂坠特写
- 三拍：上身/上肩动态→细节特写（走线/五金/内袋）→ 场景穿搭定格
- 声景：布料摩擦、拉链滑动的细节声；台词骨架「这个版型，谁穿谁直。」（体验句，非绝对化）
- 禁词重点：瘦身显白类功效暗示、品牌名（除非授权，桶标与店铺名不一致时不口播品牌）

### 6. 母婴玩具
- 钩子模式：**宝宝反应瞬间**（抓握/大笑）/ 安装前后
- 三拍：使用场景（宝宝与商品互动）→ 安全细节特写（圆角/材质手感）→ 收纳/全家福定格
- 声景：玩具声、宝宝咿呀（非语言人声写进 soundscape）、房间底噪
- 禁词重点：一切安全绝对化（「绝对安全」）、早教功效（「开发智力」）、年龄适用性夸大

## 模板变量（每商品填写）
```
商品名（净化后）／规格事实／钩子句／带入句／价值信任句／CTA句／声景清单／参考图序
```
决策记录：钩子模式与句式选择理由写进该 goods 的确认卡第 1 项（推荐方案）。

## 受众声线画像（2026-09-27 用户定规：旁白模仿商品目标人群的年龄与性别）

按商品定位选 persona，音色描述句**逐窗复述**；语气一律自然口语（像真实博主在分享），
禁播音腔（不用 announcer/broadcast 类词）。
