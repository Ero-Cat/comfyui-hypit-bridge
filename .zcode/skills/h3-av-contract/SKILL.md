# h3-av-contract：音频与镜头稳定性硬契约

本仓库 H3 生产中**已实测翻过车**的两类问题——音频乱码（babble）与中段动作失控——的
完整根因、修复写法与可执行验证。**写任何 H3 提示词前先过一遍本契约**；这里每条规则
都有对应事故记录（productions/mesugaki/notes.md，2026-09-26）。

## 0. 流程前置（最深的一次教训）

**写提示词前必须读完用户级技能 `h3-prompt-writing` 的对应参考文件**
（`references/base-en.txt` 或 `ref-en.txt`）——SKILL.md 只索引规则，具体格式（`<d>`、
说话人 ID、声景三字段）都在参考文件里。2026-09-26 的 babble 事故直接根因之一就是
"知道有这个技能、没读参考文件"。

## 1. 音频契约

### 1.1 台词必须用官方 `<d>` 格式（babble 的根因）

> 事故：16s 两窗版（v2）台词只占 1/3 时长且未标记 → 模型**自己编造语音填满窗口**，
> 全片成 babble（强制中文转写=繁体乱码、强制日语=无意义音节、auto 判 zh p=0.98——
> "听起来像说话但不是任何语言的词"）。

**规则**：台词一律写成 `(S1) says: <d>[Chinese] 原文逐字</d>`：

- 说话人 ID `(S1)`、音色描述、语速、动作**全部在 `<d>` 外面**；`<d>` 内**只有语言标签 + 原文**
  （逐字，不改写不翻译）
- 说话人首次出现时在 `<d>` 外给足身份信息（年龄/性别/音高/音色/语速）
- SVML 里尖括号写 XML 实体：`&lt;d&gt;[Chinese] 唔……哥哥~&lt;/d&gt;`
- **描述正文用英文**（官方规范要求）；台词原文保持中文不动
- v1 密集台词（2.7 字/秒）没崩、v2 稀疏台词（0.6 字/秒）全崩——**`<d>` 格式是让模型知道
  "哪些字必须逐字念"的唯一信号**，台词越稀越必须标记

### 1.2 每窗必带 `overall_soundscape`（把空白时间"指定"掉）

音频分支必须填满每个窗口的时长。没被指定的部分=留给模型即兴发挥。

- 每窗 prompt 末尾附 `overall_soundscape:`：房间底噪、窗外声、衣物/床品摩擦、**呼吸、
  笑声、喘息等非语言人声**——**动作窗把这里当"台词替代品"写满**
- 台词稀疏时显式加 **"No other voices"**（本仓库实测这是抑制加词的关键句）
- 无配乐则 `non_diegetic_music: N/A`
- 历史中文描述（无三字段）视觉分支可用但音频无保障；新脚本一律按官方结构
  （integrated_multimodal_description + overall_soundscape + non_diegetic_music）

### 1.3 声音锚（复用 AGENTS §4 规则，此处只列硬点）

- 锚 ≤12s 且 `silencedetect=noise=-38dB:d=0.30` 验收"干净"（有句间静音）后才上车
- 链式台词声线：`chainRef2va:true` + 每窗音色描述句；无锚时 `selfAnchorVoice` 跨窗
  自锚（锚自己生成的首窗嗓音），音色改纯文本直描并**明令正常音量**（禁 whisper/hushed）
- **"删除音频参考"≠"删除音色要求"**：文本直描必须补位，否则向默认嗓音漂移

### 1.4 音频接缝：窗数 = 接缝数

链式"窗"不是剪辑点（输出永远一镜到底），但**音频按窗生成再拼接**——窗数直接等于
接缝数。接缝质量用工具说话：

```bash
python3 tools/audio_seam_check.py <out.mp4> --seam <秒> [--seam ...] --budget <脚本语音秒数>
# --seam = 窗数-1 个，等窗即 duration/窗数；--budget = 台词字数 × 节奏(慢速~0.45s/字)
```

三指标判定（工具自动输出 JSON + 人读摘要，接缝全 PASS 才算过）：

| 指标 | 阈值 | 含义 |
| --- | --- | --- |
| click | 接缝 ±200 采样 max\|diff\| ≤ 全片 99.99 分位 ×1.5 | 无爆音 |
| level | **接缝 ±25ms 落在静默（瞬时 RMS < 峰值 3%）**或两侧 0.5s RMS 差 <1.5dB | 拼接最不可闻的位置=静默间隙 |
| voice | 两侧 3.5s 基频中位数差 <5% | 同一把嗓子 |

- **写法配合**：把窗尾台词/动作收在**停顿**上，接缝就落进静默（v2 实测：瞬时 RMS 0.2，
  三指标全 PASS）
- `--budget` 超出 +3s → **模型加词**（babble 同源信号），报给用户人耳复核

## 2. 镜头稳定性契约

### 2.1 窗数的两难与决策顺序

窗数同时决定三件事：**① 音频接缝数 ② 节拍漂移风险 ③ 每窗时长是否落在 17k+5 格网**。

- 事故 v1（35s/6 窗）：5 个接缝 + 中段动作洗牌（V 手势提前 13s、躺倒提前 20s、揉眼姿态
  在 4 个窗口复现）
- 修复 v2（16s/2 窗）：动作按序全中、接缝落静默——**能用更少窗就用更少窗**
- 但窗太少→单拍节奏被压缩（16s ÷ 9 拍 = 1.78s/拍），呈卡时必须把这个取舍写明给用户
- 硬边界：链式 `duration ≥ 16`；H3 单窗 ≤362 帧（15.08s）；16s÷2窗=192 帧恰在格网
  （**16s 是"2 窗零浪费"的唯一定点**，任何"更短/单窗"请求物理不可行，直接告知用户）

### 2.2 窗间衔接：禁止静持，必须"连续动作桥"

> 事故：v1 每窗开头写"接住上一窗收尾姿态约两秒"→ 模型把姿态锁死，揉眼动作跨窗复现。

- **写连续动作桥**："笑意还没收，她顺势退开半步…"——上一窗的收尾状态是下一窗动作的
  **起因**，不是需要静持 2 秒的雕塑
- CFG=1 下否定句反噬：写"画面像被她的一举一动牵引着自然推移"，不写"不要切镜/不要抖动"
- 每窗以**不可逆事件**推进（检验：两句互换剧本仍成立 ⇒ 模型也分不清）
- 人物/环境逐字复述防漂移（AGENTS §4 既有规则，不赘述）
- 一镜到底/POV 想要镜头稳定感：正写"the whole take is one single continuous shot with
  no cuts"+ POV 语义（镜头=哥哥举着的手机视线），比否定句有效

### 2.3 "对镜头说话"的字幕条先验（既有坑，保留）

提示词只能部分抑制抖音字幕条先验；QC 发现后 `clean_watermark.sh` 对 bbox delogo 是
标准兜底。

## 3. 交付前验证闭环（音频 + 画面，全客观可执行）

```bash
# ① 规格+转写（注意：从仓库根跑；whisper 必须先抽 wav，直读 mp4 会静默失败）
bash tools/verify_output.sh <out.mp4> --expect-script <txt> --expect-res 736x1280 --expect-fps 24
ffmpeg -ac 1 -ar 24000 -i <out.mp4> /tmp/a.wav && whisper-cli -m <model> -l zh -nt -f /tmp/a.wav

# ② 音频接缝三指标 + 发声密度审计（多窗必跑；单窗跑 --budget 审加词）
python3 tools/audio_seam_check.py <out.mp4> --seam <秒>... --budget <秒>

# ③ 画面 QC：1fps 全片连拍（查切镜/字幕条/身份漂移）+ 节拍网格
ffmpeg -i <out.mp4> -vf "fps=1,scale=184:320,tile=7x5" qc-1fps.png
ffmpeg -i <out.mp4> -vf "fps=1,scale=368:640,tile=3x3" -frames:v 1 qc-beats.png   # 先抽帧
```

已知工具 bug（不要误判成成片问题）：

- `watermark_detect` 对 <15s 短片取帧不足报错 → `--interval 1`；静态区 static_pixels
  占比 <1% 基本是海报/门框等静止背景误报，全分辨率目检排除
- `verify_output.sh` 必须从**仓库根**执行（子目录会断 watermark_detect.py 相对路径）
- whisper 谐音噪声是常态（大黄猫→大狠猫/大黃毛、唔/哼 语气词丢失）——**语义命中即算命中**
- 判 babble 的金标准：auto + 强制 zh + 强制 ja 三次转写全是"音节合理词语不通" → babble

## 4. 事故档案（写新脚本前扫一眼，防再犯）

| 事故 | 根因 | 契约条目 |
| --- | --- | --- |
| 16s v2 全片 babble | 台词未用 `<d>` 标记 + 密度 0.6 字/秒 + 无 soundscape | §1.1 §1.2 |
| 16s v2 模型加词至 12s/16s | 动作段时间没被 soundscape 指定 | §1.2 §1.4 |
| 35s v1 中段动作洗牌+姿态锁死 | 6 窗接缝多 + "静持两秒"写法 | §2.1 §2.2 |
| v2.1(tonghuashun) 气声听不清 | 提示词允许气声发音 | §1.3（明令正常音量） |
| 960×960 方片 | 方形脸裁片全家桶、无画幅锚 | AGENTS §4（参考#1 锚画幅） |
